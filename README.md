# 🍔 Swiggy Clone — Modern React Food Ordering Platform

A high-performance, pixel-perfect, responsive **Swiggy Web Clone** built with **React, Vite, and Modern CSS**. Features end-to-end food delivery flows including real-time restaurant search, smart category & diet filters, interactive categorized menus, multi-restaurant cart state with coupon discount calculation, and simulated live order tracking.

---

## ✨ Features

- 📍 **Delivery Location Selector:** Switch between cities and localities (Noida Sector 62, Sector 18, CP Delhi, Gurugram, Bengaluru).
- 🏷️ **Dynamic Promos & Coupons:** Interactive discount coupons (`SWIGGY50`, `NIGHTOWL`, `BIRYANIROYAL`) with live bill deductions.
- 🥘 **"What’s on your mind?" Category Carousel:** Quick-filter restaurants by Biryani, Pizza, Burgers, North Indian, Rolls, South Indian, Desserts, and more.
- ⚡ **Real-Time Search & Smart Filters:**
  - Instant fuzzy search across restaurant names, cuisines, areas, and dish items.
  - Fast Delivery (< 30 mins) filter.
  - Pure Veg mode.
  - 4.0+ Top-rated filter.
  - Price sorting (Low to High / High to Low).
- 🏬 **Swiggy Restaurant Cards:** High-res food photography, discount banner ribbon overlays, delivery times, distances, price for two, and rating badges.
- 📜 **Full Restaurant Detail & Categorized Menus:**
  - Breadcrumbs & outlet info overview.
  - "Veg Only" dish filter switch.
  - Dish cards with Veg/Non-veg indicators, ratings, descriptions, and interactive `ADD` buttons.
  - Smooth quantity steppers `[ - 1 + ]` directly synchronized with the cart.
- 🛒 **Slide-Over Food Cart Drawer:**
  - Item list with quantity steppers.
  - Cooking instructions input field.
  - Promo code validation & instant discount calculation.
  - Delivery partner tipping (₹20, ₹30, ₹50).
  - Detailed bill breakdown (Item Total, Free Delivery calculation, Platform Fee, GST, Grand Total).
- 🛵 **Live Order Tracker Modal:** Simulated order confirmation with timeline progress (Confirmed → Cooking → On the way → Delivered).
- 📱 **100% Mobile Responsive:** Optimized for desktop, tablets, and smartphones.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### Installation

```bash
# Clone the repository
git clone https://github.com/harshvgupta1/React.git

# Navigate into the project directory
cd React

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
npm run preview
```
